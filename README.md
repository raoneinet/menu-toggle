# 📁 Menu Toggle

Menu lateral com botão de abrir e fechar, criado com **HTML**, **CSS** e **JavaScript**. Ideal para incorporar em sites como funcionalidade de **menu lateral responsivo**.

---

## 🧩 Funcionalidades

- ✅ Menu lateral responsivo (abre e fecha);
- ✅ Botão **hambúrguer** no topo (inserido no `header`);
- ✅ Botão de **fechar (X)** dentro do menu;
- ✅ Estilização com fontes do [Google Fonts](https://fonts.google.com/);
- ✅ Estrutura simples e isolada (body em branco) para foco exclusivo na feature.

---

## 💻 Tecnologias usadas

- HTML5  
- CSS3  
- JavaScript  
- Google Fonts

---

## 📱 Responsividade

O menu é adaptável para diferentes tamanhos de tela, funcionando bem em **dispositivos móveis**, **tablets** e **desktops**.
